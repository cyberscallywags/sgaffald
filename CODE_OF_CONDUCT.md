# Code of conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct. In short: be welcoming, be kind, accept constructive criticism
gracefully, and focus on what is best for the community. Harassment, insults and publishing
other people's private information are not acceptable, in any project space or in public
when representing the project.

## Reporting

Report behaviour that breaks this code privately to the project's maintainers, through the
repository's **Security → Report a vulnerability** form (only maintainers can read it), or
GitHub's [report content](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam)
tools. Reports are handled in confidence.

Maintainers apply the Covenant's
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines):
correction, warning, temporary ban, or permanent ban, depending on the impact.
