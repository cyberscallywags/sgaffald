# Trademarks and brand assets

The code in this repository is released under the [MIT licence](LICENSE). The brand is not:

| Path | Terms |
|---|---|
| Everything except `brand/` | MIT, see [`LICENSE`](LICENSE) |
| `brand/` (name, crest, marks, logo, hero, palette, copy) | All rights reserved, see [`brand/LICENSE`](brand/LICENSE) |
| `examples/brands/neutral/` | Public domain (CC0), see [`examples/brands/neutral/LICENSE`](examples/brands/neutral/LICENSE) |

Copies of the brand that `uv run task sync` writes elsewhere (under `docs/content/assets/brand/`,
`mobile/src/assets/brand/`, `src/app/ui/static/`, and the generated docs pages) carry the same
terms as the folder they come from.

A project built from this template should replace `brand/` with the neutral example or its
own brand before it is published; the
[Make it yours](docs/content/handbook/make-it-yours.md) guide starts there. You may say that
your project is built with this template.
