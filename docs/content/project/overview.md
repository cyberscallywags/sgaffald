# Project overview

This section belongs to the project, not the template: replace this page with what the
project is, who it is for and the decisions it has made, and add more pages beside it. List
each page under `Project` in `docs/zensical.toml` and in the Project toctree in
`docs/content/manual.md`.

Useful things to write down early:

- **What it is for**: the problem, who has it, and what they can do once the project exists.
- **The domain**: the things the project is about, which replace the sample `Item`.
- **Decisions**: choices that will puzzle someone later, and why they were made.
- **How to run it in production**: hosting, secrets, backups and who to call.

The template's own documentation is the [Template handbook](../handbook/index.md).
